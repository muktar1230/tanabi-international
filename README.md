# Tanabi International - متجر تنابي الدولي

هذا مشروع متجر إلكتروني لبيع الأزياء التقليدية البلوشية الفاخرة، تم تطويره باستخدام مكتبة React.

## 🚀 المميزات
- عرض الأزياء التقليدية البلوشية بتصميم فاخر وعصري.
- تجربة مستخدم سلسة واستجابة مع مختلف الشاشات (Responsive Design).

## 🛠️ التقنيات المستخدمة
- **React.js**
- **JavaScript (ES6+)**
- **CSS / HTML5**
